## 2. Головна мета

Реалізувати комплексний кластерний аналіз двома основними підходами машинного навчання (метод k-середніх та ієрархічна кластеризація) у чистому Python:
1. **Частина 1: Метод K-середніх (K-Means Clustering):**
   - Побудувати базову модель k-середніх на двовимірних даних (вага та ціна) або відібраних ознаках;
   - Візуалізувати сформовані кластери різними кольорами та чітко позначити позиції центроїдів;
   - Дослідити оптимальну кількість кластерів $k$ за допомогою методу «ліктя» (Elbow Method / WCSS) або коефіцієнта силуету (`silhouette_score`).
2. **Частина 2: Ієрархічна агломеративна кластеризація (Hierarchical Clustering) на `stocks.csv`:**
   - Завантажити часовий ряд котирувань акцій `stocks.csv` (взяти зріз із 50 перших спостережень);
   - Видалити нечисловий стовпець `DATE` (зберігши його як мітки або індекс);
   - Обчислити матрицю зв'язків за методом Уорда (`method='ward'`, `metric='euclidean'`);
   - Побудувати повномасштабну дендрограму з мітками спостережень;
   - Провести інтерпретацію виявлених кластерів (як взаємопов'язані поведінки акцій різних компаній у часі).
3. **Частина 3: Кластеризація багатовимірних економічних/фінансових даних із стандартизацією:**
   - Провести нормалізацію/стандартизацію (`StandardScaler`) для запобігання домінуванню ознак з великими шкалами;
   - Розбити об'єкти на кластери та надати аналітичну характеристику кожній групі.

## 4. Детальний покроковий план

### 4.1. Демонстраційний KMeans на двовимірних даних
1. Створити вибірку даних із двома числовими вимірами (наприклад, вага та ціна або дві числові характеристики).
2. Ініціалізувати та навчити модель: `kmeans = KMeans(n_clusters=3, random_state=42, n_init=10).fit(X)`.
3. Отримати координати центроїдів: `centroids = kmeans.cluster_centers_`.
4. Побудувати графік розсіювання, де кожен кластер пофарбовано окремим кольором, а центроїди відмічені великими чорними/червоними маркерами `X`.
5. Зберегти графік: `figures/kmeans_clusters.png`.

### 4.2. Метод «ліктя» (Elbow Method) для підбору $k$
1. Обчислити значення WCSS (інерція, `kmeans.inertia_`) для діапазону $k \in [1..10]$.
2. Розрахувати `silhouette_score` для $k \ge 2$.
3. Побудувати криву інерції та зберегти: `figures/elbow_method.png`.

### 4.3. Ієрархічна кластеризація котирувань акцій (`stocks.csv`)
1. Зчитати `df_stocks = pd.read_csv('stocks.csv')`.
2. Взяти перші 50 рядків: `df_sub = df_stocks.head(50)`.
3. Відокремити дати: `dates = df_sub['DATE'].tolist()` та числові ознаки: `X_stocks = df_sub.drop(columns=['DATE'])`.
4. Стандартизувати показники або працювати з сирими значеннями згідно інструкції.
5. Обчислити зв'язки:
   ```python
   Z = linkage(X_stocks, method='ward', metric='euclidean')
   ```
6. Побудувати детальну дендрограму високої якості:
   ```python
   plt.figure(figsize=(15, 8), dpi=150)
   plt.title("Дендрограма ієрархічної кластеризації акцій (Метод Уорда)")
   plt.xlabel("Дата / Спостереження")
   plt.ylabel("Евклідова відстань")
   dendrogram(Z, labels=dates, leaf_rotation=90, leaf_font_size=8)
   plt.tight_layout()
   plt.savefig("figures/stocks_dendrogram.png")
   ```
7. Додатково: провести кластеризацію самих акцій (транспонувати матрицю `X_stocks.T`), щоб згрупувати компанії за схожістю динаміки їхніх котирувань, та побудувати дендрограму `figures/tickers_dendrogram.png`.
