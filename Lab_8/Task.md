## 4. Детальний покроковий план

### 4.1. Завантаження та конвертація даних
1. Зчитати файл транзакцій:
   ```python
   import pandas as pd
   df = pd.read_csv('Basket_data.csv', header=None)
   ```
2. Сформувати список транзакцій без пропусків (`NaN`):
   ```python
   transactions = []
   for i in range(len(df)):
       row = [str(x).strip() for x in df.iloc[i].values if pd.notna(x) and str(x).strip() != 'nan']
       if row:
           transactions.append(row)
   ```
3. Вивести первинну описову статистику: кількість транзакцій ($N = 7501$) та загальну кількість унікальних найменувань товарів.

### 4.2. Навчання алгоритму Apriori
1. Імпортувати локальний модуль:
   ```python
   import apriori as apyori
   ```
2. Викликати генератор правил із цільовими порогами:
   ```python
   results = list(apyori.apriori(
       transactions,
       min_support=0.003,
       min_confidence=0.2,
       min_lift=3.0,
       max_length=3
   ))
   ```
3. Сформувати DataFrame із результатів:
   ```python
   rules_list = []
   for record in results:
       items = list(record.items)
       for stat in record.ordered_statistics:
           base = list(stat.items_base)
           add = list(stat.items_add)
           if not base or not add:
               continue
           rules_list.append({
               'rule': f"{', '.join(base)} -> {', '.join(add)}",
               'base': ', '.join(base),
               'add': ', '.join(add),
               'support': record.support,
               'confidence': stat.confidence,
               'lift': stat.lift
           })
   rules_df = pd.DataFrame(rules_list).sort_values(by='lift', ascending=False).reset_index(drop=True)
   ```
4. Вивести топ-10 найсильніших правил.

### 4.3. Обов'язкові візуалізації
1. **Мережевий граф зв'язків (`networkx`):**
   ```python
   import networkx as nx
   import matplotlib.pyplot as plt

   G = nx.DiGraph()
   for _, row in rules_df.head(20).iterrows():
       G.add_edge(row['base'], row['add'], weight=row['lift'])

   plt.figure(figsize=(12, 9), dpi=150)
   pos = nx.spring_layout(G, k=0.8, seed=42)
   nx.draw_networkx_nodes(G, pos, node_size=1500, node_color='lightblue', edgecolors='black')
   nx.draw_networkx_edges(G, pos, edge_color='gray', arrows=True, arrowsize=15)
   nx.draw_networkx_labels(G, pos, font_size=8, font_family='sans-serif')
   plt.title("Граф асоціативних правил (Top 20 за Lift)")
   plt.axis('off')
   plt.tight_layout()
   plt.savefig("figures/apriori_rules_graph.png")
   ```
2. **Кругова діаграма часток підтримки (`Pie Chart`):**
   - Побудувати для топ-7 правил (решту згрупувати як "Other") або найчастіших наборів;
   - Зберегти: `figures/apriori_pie_chart.png`.
3. **Стовпчикова діаграма порівняння показників (`Bar Chart`):**
   - Відобразити рівні `support` та `confidence` для топ правил;
   - Зберегти: `figures/apriori_support_bar.png`.
