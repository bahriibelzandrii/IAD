## 4. Детальний покроковий план

### 4.1. Завантаження та попередня обробка
1. Зчитати файл: `df = pd.read_excel('heart.xlsx')`.
2. Перевірити пропущені значення: `df.isnull().sum()`.
3. Відокремити ознаки та цільову змінну:
   ```python
   X = df.drop(columns=['target'])
   y = df['target']
   ```
4. Розділити на тренувальну та тестову вибірки:
   ```python
   X_train, X_test, y_train, y_test = train_test_split(
       X, y, test_size=0.2, random_state=0, stratify=y
   )
   ```

### 4.2. Побудова базового дерева рішень
1. Ініціалізувати модель: `clf_full = DecisionTreeClassifier(criterion='entropy', random_state=0)`.
2. Навчити модель на `(X_train, y_train)`.
3. Зробити прогноз на тесті `y_pred = clf_full.predict(X_test)`.
4. Розрахувати точність `accuracy_score(y_test, y_pred)` та вивести матрицю невідповідностей `confusion_matrix`.
5. Зберегти графік повного дерева рішень: `figures/tree_full.png` (використовуючи `tree.plot_tree(..., feature_names=X.columns, class_names=['No', 'Yes'], filled=True)`).

### 4.3. Оптимізація через крос-валідацію (Hyperparameter Tuning)
1. Задати діапазон досліджуваного гіперпараметра:
   - Наприклад, `min_samples_split_range = np.arange(0.1, 1.1, 0.1)` (або `max_depth` від 1 до 15).
2. Для кожного значення обчислити середню помилку крос-валідації:
   ```python
   cv_errors = []
   for val in min_samples_split_range:
       clf = DecisionTreeClassifier(criterion='entropy', min_samples_split=val, random_state=0)
       scores = cross_val_score(clf, X_train, y_train, cv=5, scoring='accuracy')
       cv_errors.append(1.0 - np.mean(scores))
   ```
3. Визначити оптимальне значення:
   `optimal_val = min_samples_split_range[np.argmin(cv_errors)]`.
4. Побудувати та зберегти графік залежності: `figures/cv_error_plot.png`.

### 4.4. Навчання та оцінка обрізаного дерева
1. Навчити підсумкову модель з оптимальним параметром:
   ```python
   clf_pruned = DecisionTreeClassifier(criterion='entropy', min_samples_split=optimal_val, random_state=0)
   clf_pruned.fit(X_train, y_train)
   ```
2. Оцінити точність на тестовій вибірці: `pruned_acc = accuracy_score(y_test, clf_pruned.predict(X_test))`.
3. Побудувати та зберегти компактне візуальне дерево: `figures/tree_pruned.png`.
4. Побудувати теплову карту матриці невідповідностей: `figures/confusion_matrix.png`.
