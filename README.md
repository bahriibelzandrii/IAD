# Комплекс лабораторних робіт: Інтелектуальний аналіз даних (ІАД)

Репозиторій містить повний набір виконаних лабораторних робіт з курсу **«Інтелектуальний аналіз даних» (ІАД)**.

* **Виконав:** Багрій-Белз Андрій  
* **Група:** КН-2327Б  

---

## 📂 Структура репозиторію

| Лабораторна | Тема | Ключові методи та інструменти |
|---|---|---|
| **[Lab 1](./Lab_1/)** | Розвідувальний аналіз та візуалізація даних (EDA) | Pandas, Seaborn, Matplotlib, обробка пропусків, Boxplot, гістограми, кореляційна матриця |
| **[Lab 2](./Lab_2/)** | Регресійний аналіз даних. Кореляція | Метод найменших квадратів (OLS), $R^2$, $p$-values, діагностика залишків, гомоскедастичність |
| **[Lab 3](./Lab_3/)** | Дисперсійний аналіз даних (ANOVA) | Однофакторний та багатофакторний ANOVA, F-тест Фішера, апостеріорний аналіз Тьюкі (Tukey HSD) |
| **[Lab 4](./Lab_4/)** | Методи класифікації. Дерева рішень | DecisionTreeClassifier, критерії Gini та Entropy, матриця невідповідностей (Confusion Matrix), F1-score |
| **[Lab 5](./Lab_5/)** | Кластерний аналіз даних | Алгоритм K-Means, метод ліктя (Elbow WCSS), Silhouette Score, агломеративна кластеризація (Ward) |
| **[Lab 6](./Lab_6/)** | Самоорганізуючіся карти Кохонена (SOM) | MiniSom, топологічна кластеризація, U-Matrix, частоти активацій (BMU), компонентні карти (Component Planes) |
| **[Lab 7](./Lab_7/)** | Прогнозування часових рядів | Декомпозиція рядів (тренд/сезонність), ADF-тест стаціонарності, моделі Хольта-Вінтерса (Holt-Winters), SES |
| **[Lab 8](./Lab_8/)** | Асоціативні правила. Алгоритм Apriori | Аналіз ринкового кошика (Market Basket Analysis), One-Hot кодування, Support, Confidence, Lift |

Кожна папка містить:
* Початковий датасет або файл генерації даних
* Виконуваний скрипт аналізу (`analysis.py`)
* Jupyter Notebook (`.ipynb` для запуску в Google Colab або локально)
* Графіки високої роздільної здатності (`figures/`)
* Офіційний звіт згідно з вимогами кафедри (`report/*.docx`)
