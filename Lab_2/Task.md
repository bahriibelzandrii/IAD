## 4. Детальні інструкції до виконання

### 4.1. Підготовка та первинний аналіз `anaconda.dat`
1. Зчитати файл `anaconda.dat` за допомогою `pd.read_csv('anaconda.dat', sep=r'\s+', names=['X', 'Y', 'Gender'], header=None)`.
2. Вивести базову інформацію: `df.info()`, `df.describe()`, перші 5 рядків `df.head()`.
3. Закодувати стать `Gender`: `M` -> 0, `F` -> 1 (або категоріальний фактор).
4. Обчислити матрицю парних кореляцій `df.corr()`.
5. Пояснити значення кореляції між довжиною (`X`) та вагою (`Y`).

### 4.2. Побудова моделі парної лінійної регресії
1. Сформувати матрицю ознак `X = df[['X']]` та цільовий вектор `Y = df['Y']`.
2. Ініціалізувати та навчити модель: `model = LinearRegression().fit(X, Y)`.
3. Отримати параметри регресійної прямої:
   - Кутовий коефіцієнт (slope): `model.coef_[0]`
   - Вільний член (intercept): `model.intercept_`
   - Рівняння регресії: $\hat{Y} = a \cdot X + b$.
4. Обчислити прогнозні значення: `Y_pred = model.predict(X)`.
5. Розрахувати метрики точності:
   - $R^2$ (коефіцієнт детермінації) через `r2_score(Y, Y_pred)`;
   - $MSE$ (середньоквадратична помилка) та $RMSE$.

### 4.3. Аналіз та візуалізація залишків (Diagnostic Plots)
1. Обчислити залишки: `residuals = Y - Y_pred`.
2. Перевірити умови побудови регресії:
   - **Лінійність:** на графіку регресії точки мають рівномірно розташовуватися вздовж лінії.
   - **Гомоскедастичність:** розкид залишків не повинен залежати від величини `X`.
   - **Центрованість:** середнє значення залишків близьке до нуля ($\approx 0$).
3. Побудувати та зберегти графіки (у папку `figures/`):
   - `reg_plot.png` — точкова діаграма `(X, Y)` із накладеною регресійною прямою $\hat{Y}$.
   - `residuals_plot.png` — графік залишків `(X, residuals)` з горизонтальною лінією $y=0$.
   - `residuals_hist.png` — гістограма розподілу залишків (KDE) для перевірки на нормальність.

### 4.4. Дослідження власного набору даних (Частина 2)
1. Взяти числовий набір даних (наприклад, площа та ціна, досвід роботи та зарплата тощо).
2. Розрахувати коефіцієнт кореляції Пірсона (перевірити статистичну значущість p-value за допомогою `scipy.stats.pearsonr`).
3. Побудувати лінійну регресію та перевірити коефіцієнт детермінації $R^2$.
4. Зберегти графік залежності та регресійної прямої `custom_regression.png`.
