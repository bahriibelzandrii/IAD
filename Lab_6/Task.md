## 2. Головна мета

Реалізувати алгоритм самоорганізуючихся карт Кохонена (Self-Organizing Maps, SOM) для задач кластеризації, проєкції багатовимірних даних на двовимірну площину та аналізу просторової структури ознак:
1. **Завдання 1: Навчання мережі SOM та динаміка збіжності:**
   - Завантажити багатовимірний набір даних (наприклад, Boston Housing або альтернативний багатовимірний датасет нерухомості/економіки);
   - Відібрати ключові числові змінні (наприклад, 6–8 ознак);
   - Обов'язково стандартизувати дані за допомогою `StandardScaler` (оскільки SOM чутливий до шкал вимірювання);
   - Ініціалізувати двовимірну прямокутну/гексагональну сітку нейронів (наприклад, розмір $9 \times 6$);
   - Навчити SOM протягом 100 ітерацій (`train_batch` або `train_random`);
   - Зафіксувати зміну середньої відстані до найближчих нейронів (quantization error) та побудувати графік навчання.
2. **Завдання 2: Візуалізація карти відстаней та частоти активацій:**
   - Побудувати U-Matrix (Distance Map): відображає відстані між сусідніми нейронами (темні/світлі зони вказують на межі кластерів та щільні області);
   - Візуалізувати частоту потрапляння спостережень у нейрони (Activation Frequency / Counts) та оцінити якість топологічного відображення.
3. **Завдання 3: Відображення об'єктів (BMU) та компонентні карти (Component Planes):**
   - Знайти для кожного вхідного вектора найкращий нейрон-переможець (Best Matching Unit, BMU): `som.winner(x)`;
   - Відобразити проєкції об'єктів на U-Matrix із розфарбуванням маркерів за обраною ознакою (наприклад, рівень забруднення, ціна або категорія);
   - Побудувати компонентні площини (Component Planes) — окремі карти вагів для кожної вхідної змінної (`som.get_weights()[:, :, i]`), що дозволяє виявити кореляції між змінними в латентному просторі.

## 4. Детальний покроковий план

### 4.1. Підготовка даних
1. Завантажити датасет:
   ```python
   from sklearn.datasets import fetch_openml
   boston = fetch_openml(name="boston", version=2, as_frame=True)
   df = boston.frame
   ```
   *(Примітка: якщо OpenML недоступний локально без інтернету, використати локальний багатовимірний CSV-набір або збережені дані).*
2. Відібрати ознаки (наприклад: `INDUS`, `DIS`, `NOX`, `LSTAT`, `AGE`, `RAD`, `B`).
3. Стандартизувати матрицю ознак:
   ```python
   scaler = StandardScaler()
   X_scaled = scaler.fit_transform(df[var_names])
   ```

### 4.2. Навчання SOM (Завдання 1)
1. Ініціалізація:
   ```python
   from minisom import MiniSom
   grid_x, grid_y = 9, 6
   som = MiniSom(grid_x, grid_y, X_scaled.shape[1], sigma=1.0, learning_rate=0.5, random_seed=42)
   ```
2. Навчання та збір метрик по ітераціях:
   ```python
   num_iterations = 100
   errors = []
   for i in range(num_iterations):
       som.train_batch(X_scaled, num_iteration=1)
       errors.append(som.quantization_error(X_scaled))
   ```
3. Побудова та збереження графіка кривої навчання: `figures/som_training_loss.png`.

### 4.3. Побудова U-Matrix та матриць активацій (Завдання 2)
1. Побудувати карту міжнейронних відстаней:
   ```python
   plt.figure(figsize=(10, 7), dpi=150)
   plt.pcolor(som.distance_map().T, cmap='bone_r', alpha=0.9)
   plt.colorbar(label='Відстань між нейронами (U-Matrix)')
   plt.title('SOM Clustering - U-Matrix')
   plt.savefig('figures/som_umatrix.png')
   ```
2. Обчислити та візуалізувати кількість активацій (Counts):
   ```python
   frequencies = som.activation_response(X_scaled)
   plt.figure(figsize=(10, 7), dpi=150)
   plt.pcolor(frequencies.T, cmap='Blues')
   plt.colorbar(label='Кількість потраплянь об’єктів')
   plt.title('SOM Activation Frequency (Counts)')
   plt.savefig('figures/som_counts.png')
   ```

### 4.4. Проєкція об'єктів та компонентні карти (Завдання 3)
1. Розрахунок BMU для кожного об'єкта:
   ```python
   bmu_coords = np.array([som.winner(x) for x in X_scaled])
   ```
2. Накладання об'єктів на U-Matrix із кольоровою шкалою певної ознаки:
   ```python
   plt.figure(figsize=(10, 7), dpi=150)
   plt.pcolor(som.distance_map().T, cmap='bone_r', alpha=0.6)
   plt.colorbar(label='U-Matrix')
   scatter = plt.scatter(bmu_coords[:, 0] + 0.5, bmu_coords[:, 1] + 0.5,
                         c=df['LSTAT'], cmap='viridis', s=40, edgecolors='k')
   plt.colorbar(scatter, label='LSTAT (% населення з низьким статусом)')
   plt.title('Розподіл об’єктів на карті Кохонена (BMU)')
   plt.savefig('figures/som_bmu_mapping.png')
   ```
3. Візуалізація ваг компонентів (Component Planes):
   ```python
   weights = som.get_weights()
   fig, axes = plt.subplots(2, 4, figsize=(16, 8), dpi=150)
   for idx, name in enumerate(var_names):
       ax = axes.flat[idx]
       im = ax.pcolor(weights[:, :, idx].T, cmap='coolwarm')
       ax.set_title(f'Компонента: {name}')
       fig.colorbar(im, ax=ax)
   plt.tight_layout()
   plt.savefig('figures/som_component_planes.png')
   ```
